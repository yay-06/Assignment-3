# TECH2: Mandatory assignment 3

- [`assignment3.ipynb`](assignment3.ipynb): Assignment notebook to complete.
- [`assignment3.pdf`](assignment3.pdf): PDF version of the assignment.
- [`SCF_10pct.csv`](SCF_10pct.csv): Survey of Consumer Finances data for the assignment.

Use the TECH2 environment and keep the CSV in the same folder as the notebook.

## What you need to do

- Create a new repository from the template on GitHub (click **Use this template** >
  **Create a new repository**), clone it to your computer, and complete the
  assignment directly in `assignment3.ipynb` by adding code and text cells.
- Push your completed solution to your GitHub repository before the submission
  deadline.
- Make sure your GitHub repository is **public**, and include its URL at the top of
  the notebook.
- Submit your completed `assignment3.ipynb` **here on Canvas** by **23 October at 23:59**.

## Requirements for passing

To pass the assignment, you must submit your notebook and push your solution to your
public GitHub repository by the deadline, showing an honest attempt at the assignment.
Your solution does not have to be complete, but it must show that you have genuinely
tried.
